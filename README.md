# Bookmarks: a 3-service app on Azure

```
web  Leptos (Rust → WebAssembly)  →  Blob Storage static website
 │
api  Axum (Rust) in a container   →  Container Apps          DB_URL is a Container App secret
 │
db   PostgreSQL 16                →  Azure Database for PostgreSQL, created with Terraform
```

| Folder | What it is |
|---|---|
| `api/` | The API (`GET`/`POST /api/bookmarks`, `DELETE /api/bookmarks/{id}`, `GET /health`) and its Dockerfile |
| `web/` | The page, built with `trunk` |
| `infra/terraform/` | The PostgreSQL server |
| `.github/workflows/api.yml` | CI/CD |
| `compose.yaml` | The API with a local Postgres |

## Run locally

```bash
docker compose up --build     # API on http://localhost:8090
cd web && trunk serve         # page on http://localhost:8080
```

## Deploy

```bash
# 1. Database. The password is generated by Terraform and kept in the state file (not committed).
cd infra/terraform && export TF_VAR_subscription_id=$(az account show --query id -o tsv)
terraform init && terraform apply

# 2. API: the pipeline pushes the image. The Container App has external ingress on port 8080
#    and DB_URL as a secret: --secrets db-url=... --env-vars DB_URL=secretref:db-url

# 3. Page: the API address is set at build time; the .wasm file must be served as application/wasm.
cd web && API_URL=https://<api-url> trunk build --release
az storage blob upload-batch --account-name <storage> -d '$web' -s dist --overwrite
```

## CI/CD

Pull request: build the image. Push to `main`: build it, push it to Docker Hub tagged with the commit,
and update the Container App to that tag. Azure login uses OIDC: no Azure password is stored, and the
identity is a Contributor on one resource group only. The one stored secret is the Docker Hub token.

## Notes

- **A problem I hit:** Azure refused the `B1ms` server in France Central (`SkuNotAvailable`) although
  the region lists it. Poland Central accepted it.
- **For real production:** a private network for the database, Key Vault for the secret, two or more
  replicas with a readiness probe, logs and alerts, and database migrations.
- **Clean up:** `terraform destroy`, then `az group delete -n rg-seminar`.
